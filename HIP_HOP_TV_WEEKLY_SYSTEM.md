# HIP HOP TV WEEKLY — Production System

**One script. Three outputs.** Every weekly episode file is built to serve the show, the website, and the visual assets in a single pass.

---

## The Three Outputs

1. **The Show** — The script itself: intro, stories, closer. Each story runs about thirty seconds, built for the edit.
2. **Website Content** — News items, gig guide entries, album reviews, and any copy related to stories mentioned in the episode.
3. **Media Assets** — Everything visual tied to the episode's stories:
   - Tour posters for every tour mentioned
   - Album artwork and album-watch images
   - Photos and videos relating to all news stories covered

---

## Episode File Structure

Every weekly script file includes:

1. **INTRO** — Cold open, episode number, the week's headline stories teased.
2. **STORY ONE / TWO / THREE...** — Each story: headline, the facts, the cultural weight, the closer line.
3. **CLOSER** — Sign-off, next episode tease, social handles.
4. **MEDIA LIST** — The asset checklist for that episode:
   - [ ] Tour poster(s) for each tour mentioned
   - [ ] Album artwork for each album mentioned
   - [ ] Photos/videos for each news story covered
   - [ ] Website copy drafted for each story (news item, gig guide entry, review)

---

## Why This System

- **Efficiency:** One writing pass produces the show, the site, and the visuals.
- **Consistency:** Every episode ships with its own media list, so nothing gets missed between the edit and the website.
- **Grant evidence:** Each episode file doubles as documented track record — stories covered, artists featured, reach built — useful for Create NSW and other arts funding applications.
- **SEO:** Website content generated per episode keeps hiphoptv.com.au fresh with news, gig guides, and reviews.

---

## File Naming

`HIP_HOP_TV_WEEKLY_EP[number].md` — one file per episode, containing script + media list.
